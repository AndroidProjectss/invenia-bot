# invenia-bot

Бот поддержки учебного оператора. Человек пишет на русском или кыргызском, бот находит одну из 15 тем в `data/faq.json` и отвечает готовым текстом на том же языке. Ответ не сочиняется.

## Запуск

```bash
pip install -r requirements.txt
python main.py check
```

`check` сравнивает два поиска на открытых 40 фразах и прогоняет функцию `answer`. Сеть и ключи не нужны.

Другие команды:

```bash
python main.py ask "Балансымда канча акча бар?"
python main.py ask --chat demo "Как подключить роуминг?"
python main.py ask --chat demo "А сколько стоит?"
python main.py bot
python -m unittest discover -s tests
```

## Что вызывает жюри

Из корня репозитория:

```python
from bot.answer import answer

answer("Балансымда канча акча бар?")
# {"lang": "ky", "faq_id": 1, "confidence": 0.82, "candidates": [1, 4, 9]}

answer("Прогноз погоды на завтра")
# {"lang": "ru", "faq_id": null, "confidence": 0.17, "candidates": []}
```

- `lang` — `ru` или `ky`. Пустая фраза даёт `ru`.
- `faq_id` — номер темы из `faq.json` или `null`, если вопроса нет в базе.
- `confidence` — число от 0 до 1. С эталоном не сравнивается.
- `candidates` — до трёх номеров. Первый всегда равен `faq_id`. Если темы нет, список пустой.

Без `chat_id` функция ничего не помнит. Диалог из двух реплик идёт в один и тот же `chat_id`, следующий диалог — в другой (или после `reset`):

```python
answer("Как подключить роуминг?", chat_id="D01")
answer("А сколько стоит?", chat_id="D01")  # та же тема 4
```

Короткая реплика без своей темы («а сколько стоит?») остаётся на прошлой теме этого чата. Фраза, в которой тема названа («сколько комиссия за перевод?»), переключает тему. Между диалогами нужен новый `chat_id` или `from bot.dialog import reset`.

Пороги по открытому набору:

- ниже `0.28` — темы нет, бот отказывается и ничего не выдумывает;
- от `0.28` до `0.50` — в JSON лучший номер и три кандидата, в Telegram три кнопки;
- от `0.50` — сразу готовый ответ из `faq.json`.

## Два поиска

Оба метода смотрят на официальные вопросы и короткие разговорные формулировки. Латиница вроде `Balansymdy kantip korom` перед поиском переводится в кириллицу.

| Метод | Первый номер | Топ-3 | Слабый верный ответ | Самый похожий вопрос не из FAQ |
|---|---|---|---|---|
| rapidfuzz | 100% | 100% | 0.58 | 0.55 |
| TF-IDF, символы 3–5 | 100% | 100% | 0.57 | 0.24 |

Точность на этих 40 фразах одинаковая. В боте оставлен TF-IDF: у него чужой вопрос далеко от самого слабого верного, поэтому опечатка на скрытом наборе реже утаскивает ответ за порог отказа. Язык на тех же 40 фразах определяется верно в 40 из 40.

## Telegram и /stats

`python main.py bot` читает токен из переменной `TELEGRAM_BOT_TOKEN` или из файла `.env` (образец — `.env.example`). Токен в репозиторий не кладётся. Без токена `answer()` всё равно работает.

В чате три исхода: готовый ответ, три кнопки с похожими вопросами, отказ. `/stats` показывает, сколько вопросов бот не закрыл, и сами формулировки. Id чата и номера телефонов туда не пишутся. `/reset` забывает тему текущего чата.
