# Invenia Support Bot

## Фото, голосовые и документы

Telegram и WhatsApp принимают фото, голосовые/аудио, PDF (до 20 страниц), DOCX и текстовые файлы (TXT, CSV, JSON). Размер — до 12 МБ, извлечённый текст — до 16 000 символов; большие документы нужно отправлять фрагментами. Подпись и содержимое обрабатываются вместе. Текстовые документы и DOCX читаются локально, PDF — через pypdf; фото, сканы PDF и речь требуют `GEMINI_API_KEY`. Защищённые PDF и неподдерживаемые форматы получают пояснение. Распознанный текст служит вопросом к базе знаний, а не источником новых тарифов или подтверждением оплаты.

Живой бот: [t.me/invenia_support_bot](https://t.me/invenia_support_bot). Панель оператора: [invenia.dev](https://invenia.dev).

## Проверка жюри

Ключи, Telegram и интернет не нужны. Все команды запускаются из корня репозитория.

```bash
pip install -r requirements.txt
python main.py check
```

`python main.py check` сравнивает два поиска на открытых 40 фразах и печатает, сколько раз угаданы язык и номер темы.

Один вопрос передаётся текстом в кавычках:

```bash
python main.py ask "Балансымда канча акча бар?"
```

Та же функция из Python:

```python
from bot.answer import answer

print(answer("Балансымда канча акча бар?"))
```

Печатается одна строка JSON:

- `lang` — `ru` или `ky`;
- `faq_id` — номер темы из `data/faq.json` или `null`, если вопроса в базе нет;
- `confidence` — число от 0 до 1;
- `candidates` — до трёх номеров тем. Первый совпадает с `faq_id`. Если темы нет, список пустой.

Пустая строка даёт `lang` `ru` и `faq_id` `null`. Вызов без имени чата не помнит предыдущий вопрос.

Диалог из двух реплик идёт с одним именем чата. Вторая реплика понимается в теме первой:

```bash
python main.py ask --chat demo1 "Как подключить роуминг?"
python main.py ask --chat demo1 "А сколько стоит?"
```

Оба вызова возвращают тему 4. Другое имя чата, например `demo2`, начинает диалог заново.

## Понимание вопросов через ИИ

Для рабочего чата Telegram задайте `GEMINI_API_KEY` и `AI_UNDERSTANDING_ENABLED=1` в `.env`. Gemini исправляет формулировки, распознаёт RU/KY, переводит смысл запроса для поиска и учитывает предыдущую тему FAQ. Номер темы выбирает локальный поиск; в режиме «FAQ жюри» готовый ответ отправляется на исходном языке из `faq.json`. При ошибке API или отсутствии ключа используется прежний локальный разбор. `answer()` и `python main.py check` остаются полностью автономными. Отключение ИИ-разбора: `AI_UNDERSTANDING_ENABLED=0`.

## Проверка конкурсной части без сети

```bash
python main.py check
```

После установки зависимостей команда не требует интернета, токенов или Gemini: сравнивает два метода и проверяет 40 размеченных фраз. Для живого конкурсного бота выключите «Полная база знаний» в админке (режим «FAQ жюри»). В этом режиме ответы отправляются дословно из `faq.json` на определённом языке, при средней уверенности показываются три кнопки. Приветствия с опечатками обрабатываются отдельно. `/stats` показывает только счётчики без чужих сообщений.

Бот поддержки Invenia на русском и кыргызском языках. Он отвечает только готовыми текстами из `data/faq.json`, помнит тему короткого диалога и передаёт неизвестные вопросы оператору.

Канал для пользователей: Telegram, [t.me/invenia_support_bot](https://t.me/invenia_support_bot). Диалоги видны в панели оператора: [invenia.dev](https://invenia.dev).

Все сообщения попадают в общую SQLite-базу и отображаются в отдельной панели оператора. В панели можно искать и фильтровать диалоги, отвечать вручную, включать или приостанавливать автоответ и закрывать обращения.

## Установка

Рекомендуется Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Минимальные настройки админки в `.env`:

```dotenv
ADMIN_PASSWORD=сложный-пароль
ADMIN_SECRET_KEY=длинная-случайная-строка
ADMIN_HOST=127.0.0.1
ADMIN_PORT=8080
```

Запуск всего одной командой:

```bash
python main.py start
```

Команда одновременно поднимает админку и Telegram-бота. Если `TELEGRAM_BOT_TOKEN` пока не заполнен, Telegram пропускается, а остальная система продолжает работать. Остановка всех сервисов — `Ctrl+C`.

Панель откроется на `http://127.0.0.1:8080`. Проверка состояния доступна без авторизации на `/health`.

Через Docker всё также запускается одной командой:

```bash
docker compose up --build
```

Compose запускает админку и Telegram в одном контейнере, публикует порт админки и сохраняет SQLite-базу в `data/`.

## Telegram

Добавьте токен и Telegram ID операторов:

```dotenv
TELEGRAM_BOT_TOKEN=123456:token
TELEGRAM_ADMIN_IDS=111111111,222222222
```

Отдельно Telegram можно запустить командой:

```bash
python main.py bot
```

Команда `/stats` доступна только ID из `TELEGRAM_ADMIN_IDS`. `/reset` забывает текущую тему пользователя. Диалоги Telegram автоматически появляются в админке.

## Логика ответов

- ниже `0.28` — бот не угадывает ответ и помечает диалог «Нужен оператор»;
- от `0.28` до `0.50` — предлагает до трёх похожих вопросов;
- от `0.50` — сразу отправляет готовый ответ;
- после ручного ответа автоответ в этом диалоге приостанавливается, пока оператор не включит его снова.

Основная функция остаётся совместимой:

```python
from bot.answer import answer

answer("Балансымда канча акча бар?")
```

## Команды разработки

```bash
python main.py check
python main.py ask "Как проверить баланс?"
python main.py ask --chat demo "А сколько стоит?"
python -m unittest discover -s tests -v
```

Короткая реплика без своей темы («а сколько стоит?») остаётся на прошлой теме этого чата. Фраза, в которой тема названа («сколько комиссия за перевод?»), переключает тему. Между диалогами нужен новый `chat_id` или `from bot.dialog import reset`.

Пороги по открытому набору:

- ниже `0.28` — темы нет, бот отказывается и ничего не выдумывает;
- от `0.28` до `0.50` — в JSON лучший номер и три кандидата, в Telegram три кнопки;
- от `0.50` — сразу готовый ответ из `faq.json`.

## Два поиска

Оба метода смотрят на официальные вопросы и короткие разговорные формулировки. Латиница вроде `Balansymdy kantip korom` перед поиском переводится в кириллицу.

| Метод | Первый номер | Топ-3 | Слабый верный ответ | Самый похожий вопрос не из FAQ |
|---|---|---|---|---|
| rapidfuzz | 100% | 100% | 0.58 | 0.55 |
| TF-IDF, символы 3–5 | 100% | 100% | 0.57 | 0.24 |

Точность на этих 40 фразах одинаковая. В боте оставлен TF-IDF: у него чужой вопрос далеко от самого слабого верного, поэтому опечатка реже уводит верный ответ за порог отказа. Язык на тех же 40 фразах определяется верно в 40 из 40.

## Telegram и /stats

`python main.py bot` читает токен из переменной `TELEGRAM_BOT_TOKEN` или из файла `.env` (образец — `.env.example`). Токен в репозиторий не кладётся. Без токена `answer()` всё равно работает.

В чате три исхода: готовый ответ, три кнопки с похожими вопросами, отказ. Слово «оператор» передаёт диалог человеку: бот молчит, пока не придёт `/reset`. `/stats` показывает, сколько вопросов бот не закрыл, и сами формулировки. Id чата и номера телефонов туда не пишутся.

Нейросеть необязательна. Если в `.env` есть `GEMINI_API_KEY`, Gemini 2.5 Flash только пересказывает уже найденный абзац и не выбирает тему. Без ключа или если модель дописала новую цену или код, в чат уходит цитата из базы. `answer()` нейросеть не вызывает.



## Полная база знаний

Администратор может переключать режим прямо в верхней панели:

- **FAQ жюри** — исходные 15 тем и прежний контракт `answer()`;
- **Полная база** — конкурсный FAQ плюс проверенные записи из `data/Beeline_KG_RAG_verified.jsonl`.

Переключатель действует на Telegram и сохраняется в SQLite после перезапуска. Просроченные и непроверенные записи JSONL автоматически исключаются. Путь и пороги можно настроить через `RAG_KNOWLEDGE_PATH`, `RAG_MATCH_THRESHOLD` и `FULL_MODE_FAQ_THRESHOLD`.
